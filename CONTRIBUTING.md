# Contributing

Thanks for your interest in contributing to this project.

## Ways to contribute

- report bugs
- suggest improvements
- open pull requests
- improve documentation
- help verify Homebridge compatibility changes

## Before you start

- Please open an issue first for larger changes or new features so the maintainers can review the direction and avoid duplicate work.
- Keep changes focused and minimal.
- Prefer small, easy-to-review pull requests.

## Pull request expectations

- Include a clear description of the change and why it is needed.
- Provide relevant testing or validation details.
- Keep the diff scoped to the requested fix.
- Update documentation when behavior changes.

## Development notes

- Use the existing project test flow where possible.
- For Homebridge compatibility changes, validate the plugin against the local Homebridge v2 runtime before submitting.
- Keep compatibility with the current supported Node/Homebridge matrix in mind.
