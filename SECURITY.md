# Security Policy

## Supported Versions

The project currently supports the versions listed in the release notes and the currently maintained default branch. For security issues, please report them for the current branch only unless the maintainer asks for a different version.

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, report the issue privately by using one of the following methods:

- Open a private issue in the repository if the platform allows it
- Contact the maintainer directly through the repository owner or project contact information

Please include:

- a clear description of the vulnerability
- steps to reproduce it
- affected versions or configuration
- any possible mitigations or workarounds

We will acknowledge the report as soon as possible and work toward a fix in a timely manner.

## Disclosure Policy

We ask that private reports be kept confidential until a fix is ready. Once a fix is available, we may coordinate safe disclosure with the reporter.
